# Code of Conduct

We want this project to be welcoming and harassment-free for everyone.

**Expected:** be respectful and constructive; assume good faith; accept feedback gracefully; focus
on what is best for the project and its users; protect other people's privacy.

**Not acceptable:** harassment, insults, discrimination, personal attacks, publishing someone's
private information (including real financial data), or any other conduct that would be
inappropriate in a professional setting.

Maintainers may edit or remove comments, commits, issues and pull requests that break these
rules, and may ban contributors for repeated or serious violations. To report a problem, contact
the maintainers through a private GitHub security advisory or the contact on their profile.

This is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
